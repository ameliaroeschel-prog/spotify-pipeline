## 3. Formulas and sources

- `uncached input = input_tokens - cached_input_tokens`; `cached input = cached_input_tokens`; `output = output_tokens` (reasoning tokens are inside output and are not added again).
- `item_cost = billed_units x price_per_unit`; `price_per_unit = price_per_million / 1,000,000`; `total = sum(item_cost)`.
- Projection: `enrich = texts x cost_per_text x (1 + retry) + texts x fallback x fallback_cost_per_text`; `verify = texts x verify_rate x cost_per_verified x (1 + retry)`; `group`/`memo` = measured once.
